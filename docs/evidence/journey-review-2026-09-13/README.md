# 사용자 여정 검토의 재현 결과

[검토 문서](../../USER_JOURNEY_REVIEW_2026-09-13.md)에 사용한 2026-09-13 로컬 실험 결과다. 중단 전 생성된 JSON을 재개 후 내용 변경 없이 복사했다. 결과는 데모·합성 데이터이며 사용자 실측 기록이나 운영 DB의 상태가 아니다.

## 산식 실험: `math.json`

호출 경로는 `app.services.fitness.snapshot` 및 `app.services.progress.build_dashboard`다. 기준일은 2026-09-13, 목표는 2026-11-01 풀마라톤 3:30:00, 목표 생성일은 2026-06-01이다. PB 입력은 10K 42:13, 하프 1:38:00, 풀 3:51:00이고 계획 세션 목록은 비어 있다.

| 결과 키 | 입력·조작 | 관측 내용 |
|---|---|---|
| `no_logs` | 운동 기록 없이 PB만 전달 | 현재 예상값, 준비도, 숫자가 있는 시계열 점 수 |
| `pb_edit_rewrites_past` | 같은 입력에서 10K PB만 40:00으로 변경 | 시계열 첫 점과 목표 시작점의 변경 |
| `volume_reduction_scenario` | 아래 운동 목록으로 기준일과 14일 후 비교 | 운동량 변화에 대한 산식 민감도 |
| `nonrun_kind_not_filtered` | 빈 기록 대비 기준일에 `kind=other`, 40km, 3,600초 기록 추가 | 종목 미확인 기록이 예측에 포함되는지 |

운동량 실험의 기준 목록은 `(기준일 며칠 전, km)`로 `(1,30), (3,10), (5,20), (8,30), (10,10), (12,20), (15,30), (17,10), (19,20), (22,30), (24,10), (26,20)`이다. 모든 기록은 km당 360초, 기본 `kind=easy`다. 이후 기준일 2·4·6·9·11·13일 뒤에 각 10km를 추가하고 기준일 14일 뒤의 스냅샷을 계산했다. 실제 훈련 프로그램의 효과를 검증한 실험은 아니다.

## 저장·집계 실험: `api.json`

`COACH_MOCK=1`, `SEED_DEMO=1`과 격리 SQLite DB에서 FastAPI 앱을 `httpx.ASGITransport`로 호출했다. API 실험의 날짜는 실행일인 2026-09-13이다.

1. 데모 데이터를 넣고 인증 후 `GET /api/dashboard`를 조회했다.
2. 데모 사용자에게 Garmin 외부 활동 12km·4,200초를 `ExternalActivity`로 저장하고 대시보드를 다시 조회했다. 실제 Garmin 서버 호출은 하지 않았다.
3. 같은 날 운동 기록을 먼저 1km·420초·`kind=long`, 다음으로 8km·2,880초·`kind=easy`로 POST했다. 두 요청 모두 `pain_level=0`이다.
4. 두 응답의 ID·신규 생성 여부, 저장된 운동 수·거리 합을 비교했다.
5. 해당 기록에 모의 AI 리뷰를 생성하고 `render_recent_history`가 다음 계획에 전달하는 문자열을 확인했다.

실험별 파일 원본은 `/private/tmp/coach-journey-math-evidence.json`, `/private/tmp/coach-journey-api-evidence.json`이었다. 이 디렉터리에는 인증 토큰·비밀번호·운영 데이터가 포함되지 않는다.

## 별도로 확인된 항목

중단 전 세션에서 로컬 브라우저의 목표 대시보드, 당일 훈련 생성, 부분 수행 입력, 기록·리뷰 결과, 주간 집계, 설정을 확인했다. 기존 `api/tests/test_fitness.py`의 임시 복사본은 `17 passed in 0.03s`, 프런트엔드 임시 출력 빌드는 Vite `built in 1.04s`로 완료됐다. 두 JSON은 이 빌드·화면 검증 전체의 자동화 리포트가 아니라 위 실험의 결과만 담는다.

재개 시에는 저장된 결과를 관련 코드와 대조하고 보존했다. 실제 LLM 응답 품질, 실서비스 동기화, PostgreSQL 운영 환경, Expo 실기기 동작은 이 결과로 보증하지 않는다.
